A CSS framework is CSS code that has been written by someone else --> speeds up building.

### Examples
- [Material UI](https://mui.com/material-ui)
- [Bootstrap](https://getbootstrap.com/)
- [Tailwind](https://tailwindcss.com/)

Used through already set class naming conventions and importing their css through ```<link>```
