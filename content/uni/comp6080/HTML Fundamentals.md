
[[HTML]] stands for __Hypertext Markup Language__. It describes content on a webpage.

`<!doctype html/>` - informs file type
`<head></head>`- metadata
`<body></body>`- content that renders

## Tags & Attributes

##### Layout tags - help separate page into separate structures
`<div>` - Generic box grouping
`<span>` - Generic grouping
`<p>` - paragraph
`<h1>` - biggest header
`<h2>`- smallest header
`<ul><li></li></ul>`- unordered list
`<ol>...</ol>` - ordered list
`<table>` - table, `<tr>`- row, `<td>`- cell, `<tr><td></tr>`

##### Formatting tags
`<b>`- bold
`<i>`- italic
`<u>`- underlined

`<a></a>`- link
- href: hyperlink reference attribute
- title: hovering title
- target: where the link opens - "_blank" opens a new tab
- links need https://... if it lives outside page/source folder. Otherwise, /... works to search through page/local directory.

`<img />`- image
- src: Source attribute
- width
- height
- alt: Alternative text when url fails.

`<form></form>` - Provide structure to collect information from a user, then submit it.
- Key parts:
	- inputs & labels (type, name, value, placeholder, disabled)
	- textarea - multiline text
	- button
	- submit

`<button></button>`- button, clickable element
