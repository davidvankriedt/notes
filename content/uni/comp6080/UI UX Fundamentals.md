## UI

^9d7c73

__Alignment__:
- Humans tend to trust alignment.
- We can align items in accordance to a grid - typically 12 columns (12 is a very divisible number)
- The limit of written content is typically 1200px for readability.

__Typography__:
- Less is more. Use at most 2 different font families. Remain consistent throughout page.
- Creating a palette/table of types is useful to ensure consistency.

__Colours__:
A constrained set of colour creates a sense of cohesion.

Before starting a project, choose:
1. A primary hue with variants
2. A secondary hue (optional)
3. Grayscales

For colour palette to remain harmonious (have a similar hue), use [HSL](https://www.w3schools.com/colors/colors_hsl.asp) or [LAB](https://en.wikipedia.org/wiki/CIELAB_color_space).

Tools:
- [colorizer](https://colorizer.org)
- [paletton](https://paletton.com)

__Help people find things__:
We use a visual hierarchy to make what's most important standout.

1. Size --> bigger means important
2. Colour --> brighter means important
3. Contrast --> contrasting things draw attention
4. Spacing --> big margins create importance
5. Alignment --> misalignment makes things stand out
6. Repetition --> puts things on same level

## UX

__Help people use things__:

[[Affordances]] - Visual property of element that lets user know they can do something with it.

__Types of affordances__:
- Explicit: Tells people how to interact.
- Pattern: Uses common pattern to imply interaction.
- False: Looks like it would do something it can't (should be avoided).
