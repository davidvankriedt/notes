# Cognitive Load Theory

## Split Attention Theory
## CLT Principles
 - Split attention effect (-) - It's bad to spread information such that users have to construct the whole picture.
 - Redundancy effect (-) - info is not essential for understanding.
 - Modality effect (+) - info presented in both auditory and visual form.
 - Transitory information effect (+/-) - transient information, info that is not permanent.

- reduce search (+)
- using diagrams (+) - It's good to have a balance of diagrams and text.
