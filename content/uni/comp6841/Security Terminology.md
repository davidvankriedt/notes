
__Bugs__ - mistakes which programmers usually make.
__Vulnerabilities__ - Bugs which cause security incidents.
__Exploitation__ - when someone takes advantage of a vulnerability.
__APT__ (Advanced Persistence Threat) - An attack that can take weeks. 
__Data__ - Unorganised facts.
__Information__ - Data that has been processed.
__Security Theatre__ - An appearance of safety without meaningful risk reduction.
__PII__ (Personally Identifiable Information) - Data that can be used to distinguish a specific individual
